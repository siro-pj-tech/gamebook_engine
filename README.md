# 📖 Web GameBook Engine & Editor

ブラウザだけで軽快に動作する、JSONデータ駆動のゲームブック・ノベルゲームエンジンです。
シナリオデータ（冒険の書）を入れ替えるだけで、ファンタジーからホラー、長編ノベルまであらゆるジャンルのテキストアドベンチャーを遊ぶことができます。

[▶ すぐに遊ぶ (Play Now)](https://siro-pj-tech.github.io/gamebook_engine/)

## ✨ 特徴
* 🚀 **完全スタンドアロン（APIキー不要）**
  プレイ時に外部APIとの通信を行わないため、超高速で動作します。プレイヤーはサイトにアクセスしてJSONを読み込むだけで、すぐに遊べます。
* 🤖 **AIプロンプトジェネレーター内蔵（制作者向け）**
  エディターに内蔵されたジェネレーターに「アイデア」を書き込むだけで、ChatGPTやGeminiなどのAIにこのゲームブックに対応させた完璧なゲームデータ（JSON）を執筆させるための「専用プロンプト」を生成できます。
* 📱 **快適なタブUI ＆ スマホ対応**
  長文のノベルゲームにも対応。本編テキスト（📖）と、過去の行動やシステムメッセージを確認できる履歴タブ（👣）を搭載し、スマートフォンでもレイアウトが崩れません。
* 🎵 **マルチメディア対応**
  シーンごとの画像表示（アスペクト比を保持して綺麗に収まる額縁表示）、ループBGM、選択肢を選んだ際の効果音（SE）に対応しています。

## 🎮 遊び方
1. 上記のリンクからゲームエンジンにアクセスします。
2. プルダウンから遊びたい「冒険の書」を選択するか、手持ちのJSONファイルを読み込ませます。
3. 「物語を始める」をクリックしてゲームスタート！
4. 途中でやめる時はフッターの「しおりを作成」を押し、進行状況をJSONとしてダウンロードしてください。再開時は「しおりから再開」でそのファイルを読み込みます。
> **※注意**
> サンプルシナリオは予告なく変更する場合があります。

## 🛠️ ゲームの作り方 (クリエイター向け)
あなただけのオリジナルゲームを作成し、世界に公開しましょう。

1. **エディターを開く**: `/editor.html` にアクセスします。
2. **AIでベースを作成**: 画面右側の「🤖 AI用プロンプト・ジェネレーター」に作りたいゲームのあらすじを入力し、「プロンプトを生成する」を押します。
3. **AIチャットでJSONを出力**: 生成された指示文をコピーし、お好きなAI（ChatGPT, Gemini等）に貼り付けます。出力されたJSONをファイルとして保存します。
4. **エディターで仕上げ**: 保存したJSONをエディターの「📂 JSONを読込」からインポートし、画像やBGM・効果音を設定します。
   > ⚠️ **【重要】画像の推奨サイズについて**
   > 画像サイズは **600x400ピクセル前後 (JPG/WEBP形式で数100KB程度)** を強く推奨します。
   > 本エンジンは画像を文字データ(Base64)に変換してJSONファイル内に直接埋め込む仕様のため、高解像度の画像（4Kやスマホのオリジナル写真など）をそのままアップロードすると、JSONファイルの容量が数MB〜数十MBに膨れ上がり、ブラウザのフリーズや動作遅延の原因になります。
5. **完成**: 「💾 JSONを保存」で最終版を出力すれば、ゲームカセットの完成です！

## 🎵 オリジナルの音楽・効果音を設定する方法

このエンジンでは、ご自身で作成したJSONカセット単体を他の人に配布して遊んでもらうことができます。
その際、オリジナルのBGMや効果音を鳴らすには、音声ファイル（MP3）をインターネット上に置き、その**「直リンクURL」**をエディターのサウンド入力欄に貼り付ける必要があります。

ここでは、無料で使える **Google Drive** を活用した設定方法を解説します。

### 手順：Google Driveで「直リンク」を取得する

1. **アップロード**
   Google Driveに、使用したいMP3ファイル（例：`my_bgm.mp3`）をアップロードします。
2. **共有設定の変更**
   アップロードしたファイルを右クリックし、「共有」を選びます。
   一般的なアクセスを「制限付き」から **「リンクを知っている全員（閲覧者）」** に変更し、「リンクをコピー」を押します。
3. **ファイルIDの抽出**
   コピーしたリンクは以下のような形になっています。
   `https://drive.google.com/file/d/【ここの長い文字列がID】/view?usp=sharing`
4. **直リンクへの変換**
   コピーしたファイルIDを使って、以下の形式のURLを自分で作成します。
   `https://drive.google.com/uc?export=download&id=【先ほどのID】`
5. **エディターへ入力**
   作成した直リンクURLを、カセットエディターの「サウンド」欄にそのまま貼り付けます。

これで、あなたが作成したJSONファイルを誰かが読み込んだ際、自動的にGoogle Driveから音声がストリーミング再生されるようになります！

> **※注意**
> 大量のアクセスが予想される場合、Google Driveの制限により一時的に再生できなくなることがあります。本格的にゲームを公開する場合は、ご自身でサーバー（GitHub Pagesなど）を用意し、エンジン一式と一緒に `sound` フォルダ内に配置して公開することをおすすめします。

## 📁 ディレクトリ構成
GitHubで公開する際は、以下のようなフォルダ構成にしてください。

```text
your-repository/
 ├── index.html         # ゲームエンジン本体 (v3.2)
 ├── editor.html        # カセットエディター (v2.1)
 ├── bg_gamebooks.png   # ゲームブック背景画像
 ├── preset_list.json   # サンプルシナリオのプルダウンリスト
 ├── sample.json        # プリセット用のシナリオ
 └── sound/             # 音楽・効果音用フォルダ
      ├── bgm_01.mp3
      └── se_door.mp3
```
